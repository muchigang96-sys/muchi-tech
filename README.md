# muchi_tech

Персональный сайт Константина Горбачева: услуги, цены и портфолио.

## Открыть сайт

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

## Содержание

- Рабочий стол с перемещаемыми ярлыками услуг.
- Окна с описаниями услуг, ценами и портфолио.
- Анимированный цифровой портрет и информация о специалисте.
- Фон с символами Матрицы и поддержкой уменьшения движения.
- Кнопки связи через Telegram с подготовленным текстом сообщения.

HTML, CSS и JavaScript находятся в одном файле `index.html`.

## Редактирование

Описания услуг находятся в объекте `var data`. Стили — в теге `<style>`, логика — в тегах `<script>`. Данные портрета встроены в файл. Сборка и внешние библиотеки не используются.
